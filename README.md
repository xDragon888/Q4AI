# Q4AI 探索计划

面向量子效应、量子启发算法和物理概率计算的新型 AI 研究规划。文献检索基线为 **2026-10-29**，研究内容为中文。

## 打开页面

下载仓库后，使用现代浏览器打开 [Q4AI探索计划.html](Q4AI探索计划.html)。页面为独立 HTML，无需安装依赖、启动服务器或联网加载脚本。

页面包括：

- 20 篇一手研究文献及其证据边界、阅读深度和原文链接。
- 10 个技术方向的算法、硬件、材料与穿戴可行性对比。
- 12 个月探索路线图、阶段门和 8 项原型实验协议。
- 可编辑的实验进展、JSON 导入导出、周报和带进展 HTML 快照。

论文原文与 PDF 链接需要联网。页面末尾的 Kipu 报告链接仅供已有对应桌面目录的本地使用者使用，该报告不包含在此仓库。

## 进展记录

实验初始状态均为待启动；文献中的结果为原作者报告，不代表本项目已独立复现。

工作台记录保存在当前浏览器中，不自动上传或同步。移动文件、清理缓存或更换浏览器可能影响记录关联，请定期导出 JSON。向同事分享当前记录时，可导出带进展 HTML；多人更新需人工交换 JSON，导入会替换现有记录。

仓库忽略默认命名的进展备份、周报和 HTML 快照。对外提交前，应逐项检查自行添加的实验数据与附件。

## 更新内容与生成页面

需要 Node.js，无第三方依赖：

```sh
node build.cjs
```

| 文件 | 用途 |
| --- | --- |
| `research-data.js` | 人工整理的一手文献数据源 |
| `report.template.html` | 正文、布局与交互源文件 |
| `build.cjs` | 将文献数据嵌入模板 |
| `Q4AI探索计划.html` | 可独立分享的完整页面 |
| `Q4AI文献索引.json` | 生成的文献索引 |

编辑源文件后重新运行生成命令，并将源文件与生成结果一起提交。重新生成会覆盖仓库内的 HTML 和文献索引；浏览器内的进展记录不在生成源文件中。

## 证据与范围

本计划区分经典量子启发算法、相干量子计算与采用量子器件的经典概率计算。论文证明、数值实验、器件演示和系统性能分别评估。优先级、人员配置、时间安排与成功门槛属于规划建议。

当前交付为文献地图与研究规划，不构成通用智能、量子计算优势或穿戴设备性能已经实现的声明。
