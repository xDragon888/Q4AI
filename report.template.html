01 / RESEARCH THESIS

把公司的长期判断，写成可被验证的研究问题

建议采用“双轨探索”：一轨用量子启发与物理器件降低 AI 的资源成本；另一轨追问真正的量子资源能否创造经典系统难以替代的学习能力。近期优先做张量压缩、储备池与概率决策三类可比较原型，逐步决定量子硬件投入。

最贴近愿景的四组文献

模型资源：P01 · 2026 量子空间优势 + P02 · 张量压缩。新型动态结构：P04 / P05 · 量子储备池。持续适应：P08 · 可塑性。材料到低功耗决策：P13 · 铁电隧穿概率位。

H1 · 资源效率

在同样任务质量下，结构化关联或物理计算能否减少内存、每次决策能耗和延迟？参数数目只是其中一个指标。

H2 · 学习结构

固定动力学、酉约束和分层结构能否用更少更新实现记忆、迁移与持续适应？量子效应是否必要？

H3 · 协同与自主

在明确的通信限制和任务定义下，能否提高协作成功率、长程任务完成率并减少人工干预？

对起点做两项校准

GPU 依赖是当前主流训练与部署方式的资源瓶颈，并非智能只能在 GPU 上实现的物理定律。较大规模可以改善能力，但参数量也不是智能的唯一来源；压缩、小模型、检索、外部记忆和推理预算必须作为强经典对照。张量压缩已有直接相关的算法实验。[P02]

截至本次检索，所列证据没有建立“纠缠 + 叠加 + 隧穿 ⇒ 通用智慧、自主意识或任意模型指数压缩”的链条。公司的愿景适合作为长期假设；现阶段宜将“灵光”“直觉”分别操作化为新组合任务泛化与固定延迟内的一次决策质量，不把它们当成已经发现的物理效应。

本节优先级、假设与路线建议均为本计划的分析判断；论文中的证明与实验只适用于各自明确的任务和条件。

02 / EFFECT → MECHANISM → TEST

量子效应必须经过算法与系统接口，才能产生价值

效应 / 概念可能的计算作用不能直接推出关键验证
叠加与干涉设计振幅演化与采样分布；在明确查询模型下节省资源。P01 P07不能一次测量读取 2ⁿ 个任意结果；态制备和读出不免费。输入加载、查询次数、可观测量、shots 与经典输出大小。
纠缠多体关联表征；特定无通信博弈的非经典协调。P05 P16不能靠纠缠传递任意新消息；不提供超光速跨设备“思想互联”。去纠缠消融、共享随机性对照、分发与消耗速率；全样本而非只看成功筛选样本。
隧穿 · 优化在某些能量地形中跨越能垒；退火采样启发式。P12不能保证任意 NP 难问题快速找到全局最优。对窄高与宽能垒分别测试；强经典求解器、嵌入及成功概率成本。
隧穿 · 器件FTJ / MTJ 的读出或控制机制，配合随机开关实现概率位。P13 P14器件依赖量子物理不等于系统使用相干量子算法；随机涨落不等于叠加。概率曲线、互相关、温漂、寿命及包含外围电路的整板能耗。
量子启发张量网络、模拟退火、概率 / 能量模型和酉几何约束可在经典机器运行。P02 P15经典计算上的效果不能被表述为量子硬件优势。区分结构收益、算法收益、专用硬件收益与真正量子收益。
训练性的悖论需要认真研究：量子态空间很大，并不代表更容易训练。过强纠缠、过深线路、噪声与测量开销都可能降低可学性；部分避免贫瘠高原的结构又可能允许高效经典代理。必须寻找适合任务的结构，而不是把“纠缠更多”当成优化目标。[P17]

05 / PROPOSED ARCHITECTURE

候选原型：感知—动态记忆—约束决策

下面是本计划提出的待验证架构，不是任何一篇论文已经证明的完整系统。将稳定知识、动态状态与行动选择分开，可逐个替换模块，查清收益来自哪里。

01 感知与编码IMU / 语音 / 可选量子传感
固定带宽、采样率与预处理；先用公开数据回放。
02 动态记忆核心经典 ESN ↔ 量子储备池 ↔ 酉约束网络
共享输入与读出，比较记忆和适应性。
03 稀疏知识接口压缩小模型 + 本地检索
存储稳定知识；避免要求量子态保存全部语言知识。
04 决策与反馈约束图 / 能量模型 / 概率位
选择动作，报告置信度、规则可行性与更新时间。

本地实时闭环

传感 → 状态估计 → 有限动作集 → 反馈。使用 MCU / 手机 NPU，设定断网仍能工作的时限；云 QPU 不放入第一版实时闭环。

离线研究与增强

量子特征、候选优化、模拟与训练在实验环境完成；只在有可复现收益时生成经典代理或端侧参数。云访问保留为实验后端。

把“人类能力增强”锁定在一个可测任务

首个建议任务为穿戴动作意图识别 + 低时延提示：用 IMU / 肌电公开数据起步，验证跨用户泛化、漂移适应和错误提示率，再决定自采与硬件集成。量子磁传感可作为另一条独立应用线：只有当目标信号使其有明确必要性时再进入。二者不混为同一已完成原型。[P19]

量子资源的因果检查：保留同样输入、可观测输出、可训练参数和测量预算，依次替换为无纠缠、经典随机、张量网络与同构经典酉模块。只有替换后收益显著下降且对照足够强，才进一步讨论量子资源的独立贡献；仅展示纠缠见证不够。
06 / TWELVE-MONTH ROADMAP

采用相对周次，W1 为团队正式启动周；尚未确定实际启动日。下列周期、门槛与人员配置均是规划建议，未获预算批准，不代表已开展实验。

W1–W2
理论梳理

阶段 A · 定义问题、假设与资源模型

T1 审计 P01 / P18：输入与输出、量子 / 经典内存、数据访问、学习复杂性假设。T2 比较 QRC / QCNN / 忆阻器的记忆与训练结构。T3 审计生成优势任务。T4 确认穿戴任务和数据来源。建立文献证据卡、失败条件与数据划分。

G0 · 启动门：每项实验有一页预注册协议、至少一个强经典基线、可获得数据和负责人。若核心理论优势依赖现实不具备的输入接口，保留为理论支线，不进入产品收益测算。
W3–W6
经典与仿真

阶段 B · 建立三条可运行参考线

E1 做张量压缩；E3 做小储备池与时序对照；E6 做概率位软件 / 电路参考。并行运行 E2 同构经典适配器和 E4 酉几何对照。冻结训练 / 验证 / 测试集，记录种子、参数、任务误差和真实用时。

G1 · 可复现门：至少两条路线可在干净环境重跑；报告所有失败实例和预处理时间。若收益只来自降低精度或增加预算，归因到相应因素并重做消融。
W7–W10
小规模硬件

阶段 C · 只对有希望的模块做真实设备验证

选择 1–2 个模块在云 QPU、合作光学台架或 FPGA 上运行。先用仿真估计 shots、线路深度与预算，再做噪声扫描与同构对照。硬件暂不可得时，明确保留“仿真结果”，不升级证据等级。

G2 · 机制门：候选模块在至少两个任务 / 数据条件、多个种子下有一致收益，报告 95% 区间；测量 / 编码 / 外围能耗不抵消目标收益。未通过则停止本轮硬件扩展，保留经典替代路线。
W11–W13
90 天评审

阶段 D · 决定继续、转向或停止

对每条路线分别提交复现实验包、资源账、反事实对照和下一阶段成本。形成一份内部技术汇报与一份适用于管理层的决策页。先回答“是否值得做下一个实验”，再讨论产品承诺。

G3 · 投资门：至少一条路线在任务质量约束下达到预注册内存 / 能耗 / 延迟目标，并完成第二人独立重跑。若都未通过，以负结果结项本轮，不用扩大参数或换弱基线掩盖失败。
M4–M6
系统原型

阶段 E · 单任务、单设备、可断网运行

选择动作意图识别等一个任务，整合传感回放、动态核心、压缩知识与约束决策。能效收益达到门槛后再询价器件合作；不预设自建材料线。完成设备漂移、跨用户和缺失输入测试。

G4 · 系统门：建议工程目标：本地 P95 决策时延 ≤100 ms（单独报告传感窗口延迟）、计算模块平均功耗 ≤200 mW，任务质量满足原应用标准。数值为待确认目标，不是已测性能。
M7–M12
扩展与复核

阶段 F · 多设备、长期适应和可迁移性

先扩到 2–3 个经典连接设备，测掉线、带宽和长期更新；E8 的纠缠协调作为独立理论 / 网络实验。至少增加一个未用于开发的新任务，量化适用范围，形成技术转移与下一年度决策。

G5 · 扩展门：收益在新增设备、噪声与任务漂移下仍成立；外部 / 独立评测可重现。若只有单任务有效，则定位为专用智能组件，不外推通用智能。

原模型、仅量化、仅 TT / MPO、TT / MPO + 同档量化四组；额外加入 SVD 低秩、蒸馏与同大小小模型。报告恢复训练的样本和计算成本。
建议通过线
相对“仅同档量化”基线，实际模型文件 / 常驻权重再减少 ≥30%；任务得分下降 ≤1 个百分点（或 PPL 相对增加 ≤3%，按任务择一预注册），P95 延迟不恶化超过 10%。
失败 / 停止
张量收缩导致延迟或每次决策能耗显著升高，或新增压缩只靠更多精度损失；先修正内核或保留经典压缩结论，不归因为量子优势。
产物 / 文献
各层秩扫描、权重 + KV cache + 激活内存分账、质量—内存 Pareto 图。P02
E2 · 量子适配器的收益是否来自其数学结构？
任务与规模
冻结同一小语言模型；在同一层放置小 Cayley 块。先执行经典矩阵版本，再用 2–6 比特模拟 / 云设备测试可获得的小块。
强对照
同构经典 Cayley、等参数 LoRA、随机固定酉、相同块布局；匹配训练语料、训练步数、寻优预算，报告不同精度结果。
建议通过线
首先要求改善在独立测试集上稳定；只有 QPU 相对于同构经典执行在同质量下减少总资源才声称执行价值。若仅优于无适配器模型，归因为适配器收益。
失败 / 停止
经典小矩阵等价且更快 / 更省电：停止将 QPU 接入实时链路，保留结构研究。不能以处理器总比特数替代实际线路规模。
产物 / 文献
全流程时延、状态制备与可观测量重构成本、真实使用比特与门数。P03
E3 · 动态量子记忆能否以少训练成本处理时序？
任务与规模
先测延迟 XOR / NARMA10 / 记忆容量，再测穿戴动作数据；仿真从 4–8 比特自旋储备池或有限模式光学模型开始。按受试者和时间划分，防止窗口重叠泄漏。
强对照
等训练参数与匹配状态规模的 ESN、小 GRU、状态空间 / 线性模型；对于光学高斯平台加入匹配的经典数字孪生。读出层和训练预算一致。
机制消融
固定 / 去耦合拓扑、去纠缠通道、退相干扫描、可观测量数量与 10² / 10³ / 10⁴ shots 梯度；区分物理状态记忆和经典反馈缓存。
建议通过线
在两个任务中，相同质量下训练更新量或可测总能耗减少 ≥30%；或者相同资源下测试误差降低 ≥10%（相对），95% 区间支持改善。小仿真收益只作为机制线索。
产物 / 文献
记忆—非线性—噪声曲线、读出训练和实际测量成本。P04 P05 P06
E4 · 酉约束是否带来持续可塑性与更少干预？
任务与规模
先做 20→100 个连续置换 / 分布漂移任务；再做有干扰变化的有限动作环境。记录新任务学习、历史任务遗忘和人工修正。
强对照
经典正交 / 酉网络、权重约束、回放、持续反向传播 / 重置策略、同算力 QNN；把几何结构效果与量子硬件效果分开。
建议通过线
后期新任务恢复步数较最佳经典基线减少 ≥20%，历史平均得分下降不超过预注册容限，并在第二类漂移上复现；自主性以任务成功率与人工干预率独立报告。
失败 / 停止
若正交经典网络复现全部收益，就归因为可移植的几何启发；不声称量子独占。若改善学习新任务但加剧遗忘，应报告权衡。

E5 · 能量模型能否在固定预算内改进决策？
任务与规模
先用 16–24 个二元变量的小 HUBO 问题验证精确解，再扩规模。对 LLM 聚合冻结同一候选池；对穿戴任务用有限动作与明确约束，不让每种方法重新生成候选。
强对照
精确枚举（小例）、支持同一目标的 MILP / CP-SAT 建模、带集群更新的并行回火、SA、概率计算、QPU / 退火；高阶降阶时计入辅助变量与开销。
建议通过线
同一可行性与目标容差下，端到端 TTS₉₉ 或 J/成功减少 ≥20%，并在留出的真实结构实例上复现。单核 SA 胜出比较不足以说明量子优势。
失败 / 停止
若多次 LLM 采样或建模成本主导，先优化候选池；若强经典解法持平或更好，部署经典求解器，保留量子研究支线。
产物 / 文献
实例、目标函数、可行率、最佳已知解差距、所有重启时间。P11 P12 P15
E6 · 隧穿概率位能否降低完整决策系统的能耗？
任务与规模
先以软件 / FPGA 实现 32–128 个概率位作参考，再选择可获得的 FTJ / MTJ 器件或合作小阵列；不把软件随机数结果称为器件实测。
强对照
MCU / CPU 随机采样、FPGA 伪随机概率位、相同目标与采样误差下的最佳求解；匹配温度、采样间隔、独立链和通信。
器件检查
概率—偏置曲线、自相关 / 互相关、温漂、循环寿命；读写、比较器、ADC / DAC、突触互连和主机全部纳入系统功耗。
建议通过线
相同任务质量下整板 J/成功降低 ≥30%，有效独立样本吞吐不下降，温漂校准不抹去收益；通不过则不进入定制流片。
产物 / 文献
功耗账、概率标定与可扩展互连模型。每位写功率与系统功耗分别报告。P13 P14 P15
E7 · 小量子模型能否产生经典难以替代的分布？

E8 · 纠缠能否改善严格限定的设备间协调？
任务与规模
先复现均匀输入 CHSH 博弈的仿真；再讨论一个明确无运行时消息的决策任务。预共享纠缠的准备与分发属于前置资源。
强对照
穷举 / 求解最佳经典共享随机性策略；标准 CHSH 无通信上界为 75%，理想量子上界约 85.36%。加入现实可用经典低带宽通信对照，分别注明规则。
建议通过线

失败 / 停止
量子方案额外共享了任务信息、只统计成功探测或忽略分发消耗；协议无效或需要重设计。不能据此声称普通数据能零通信传输。

08 / FAIR EVALUATION

同时衡量质量、资源和可复现性

愿景操作化指标必须控制的因素
压缩与降低 GPU 依赖模型文件、常驻 RAM、峰值 RAM、KV cache；J/任务、P50 / P95 延迟同任务质量 / 上下文 / 精度 / 批次；分开训练、恢复训练和推理资源
更好的泛化 / “灵光”未见组合的成功率、分布外性能、少样本曲线、校准误差避免数据泄漏；对照小模型 + 检索、相同候选数和推理预算
快速直接决策一次决策准确率、可行率、固定截止时间内成功率、TTS₉₉包含输入窗口、编码、测量、重启、通信、后处理；分别报告窗口与计算时延
自主性与持续学习长程任务成功率、每百任务干预次数、新任务恢复步数、历史遗忘相同工具和动作范围；同样的人类反馈预算，记录失败轨迹
跨设备协作每次协作传输字节、有效吞吐、掉线恢复、设备数扩展曲线经典通信和纠缠分发 / 消耗分别记账，所有损失事件计入
穿戴式可用性整机平均 / 峰值功耗、重量、续航、热、运动干扰下质量传感器、光源、探测器、主机和无线连接全部计入；不以核心器件 nW 替代整机 mW
E / 成功 =（采集 + 编码 + 计算 + 测量 + 通信 + 后处理 + 分摊待机）总能耗 / 成功次数
TTS₉₉ = t_run × ceil[ln(0.01) / ln(1 − p_success)] + 一次性设置开销

TTS 公式适用于独立同分布重启、0 < p_success < 1；有相关采样时先估计有效独立次数。p=1 时一次运行，p=0 时不能得到有限 TTS。共享 QPU 无法获得整机能耗时，只报告可测耗时与注明边界的估算，不声称已证能效优势。

统计与数据协议

建议至少 5 个独立种子并匹配寻优预算；报告全部种子、95% 置信区间和失败率。穿戴数据按受试者 / 会话分组，先分组再切窗；时间序列按时间阻断。样本不足时如实扩大不确定性。

复现与归因

归档代码 commit、环境锁文件、数据划分哈希、模型 / 电路版本、shots、门深、校准时间、设备、功率测量方法和原始日志。第二人从归档重跑；把仿真、器件和系统结果分栏保存。
